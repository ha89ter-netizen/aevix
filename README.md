# AEVIX

Премиальный Next.js сайт AEVIX с AI-консультантом для анализа малого бизнеса.

## Установка

```bash
pnpm install
pnpm dev
```

Проект использует Next.js App Router, TypeScript, TailwindCSS, Framer Motion, GSAP, Lenis и официальный OpenAI Node.js SDK.

## Локальный OPENAI_API_KEY

1. Создайте файл `.env.local` в корне проекта.
2. Добавьте ключ:

```bash
OPENAI_API_KEY=sk-...
```

Ключ читается только на сервере через `process.env.OPENAI_API_KEY`. Не добавляйте `.env.local` в git.

## OPENAI_API_KEY в Vercel

1. Откройте проект в Vercel.
2. Перейдите в `Settings` → `Environment Variables`.
3. Добавьте переменную `OPENAI_API_KEY`.
4. Вставьте значение ключа OpenAI.
5. Выберите нужные окружения: `Production`, `Preview`, `Development`.
6. Сохраните переменную и redeploy проекта.

## Проверка AI-консультанта

1. Запустите проект локально.
2. Откройте главную страницу.
3. В окне `AI-демо` введите описание бизнеса, например:

```text
У меня барбершоп, запись клиентов ведется вручную
```

4. Нажмите кнопку отправки или `Enter`.
5. `Shift+Enter` добавляет новую строку.
6. Ответ должен появиться в окне анализа. Кнопка `Обсудить это решение` открывает попап бесплатной консультации с готовой ссылкой на WhatsApp/Telegram.

API endpoint:

```text
POST /api/business-analysis
```

Тело запроса:

```json
{
  "message": "У меня барбершоп, запись клиентов ведется вручную"
}
```

## Заявки с формы на почту

Форма «Оставьте заявку» отправляет заявку на сервер, а он — письмом через
[Resend](https://resend.com). WhatsApp в этом пути не участвует.

Нужны **две** переменные, и обе обязательны: без любой из них `/api/lead` отвечает `503`, а
человек видит честную ошибку отправки. Молча терять заявку или слать её на захардкоженный адрес
маршрут не станет — это осознанное поведение, а не недоделка.

1. Зарегистрируйтесь на resend.com и создайте API-ключ.
2. Локально — в `.env.local`, на проде — в Vercel: `Settings` → `Environment Variables`, затем
   redeploy:

```bash
RESEND_API_KEY=re_...
LEADS_TO_EMAIL=куда-падают-заявки@example.com
```

`LEADS_TO_EMAIL` — приватная настройка, а не публичный контакт: адрес, показанный на сайте,
живёт в `contacts` (`src/components/site-experience.tsx`) и совпадать с этим не обязан.

### Ограничение, из-за которого письма могут не дойти

Пока домен в Resend не подтверждён, письма уходят с sandbox-адреса `onboarding@resend.dev`, а он
доставляет **только на адрес владельца учётки Resend**. Значит либо в `LEADS_TO_EMAIL` стоит
именно этот адрес, либо домен подтверждён и отправитель задан через `LEAD_EMAIL_FROM`
(например, `AEVIX <заявки@aevix.kz>`). Иначе письмо не дойдёт, хотя в логах отправка будет
выглядеть успешной.

То же ограничение действует на **коды входа в аккаунт** — они идут тем же Resend.
